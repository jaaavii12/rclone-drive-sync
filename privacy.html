Privacy Policy

Rclone Drive Sync — Last updated: 17 November 2026

Purpose

Rclone Drive Sync is a personal automation operated by its owner to synchronize PDF documents from a private GitHub repository to specific Google Drive folders.

Google data accessed

The automation uses the permissions granted through Google OAuth to access Google Drive. It lists destination folders and reads file metadata to synchronize PDF documents. It may create, update, and delete files within the configured destination folders as part of synchronization. The exact permissions are those shown on the Google consent screen.

How data is used

Google Drive data is used exclusively to carry out the owner's requested synchronization. It is not used for advertising, profiling, or sale to third parties.

Storage and security

OAuth configuration is stored locally by the owner and provided to GitHub Actions via a repository secret. GitHub Actions uses the configuration during workflow execution. The owner is responsible for protecting access to the Google account, the repository, and its credentials.

Sharing and retention

The automation interacts with Google Drive and GitHub Actions to perform synchronization. It does not intentionally send Google Drive content to any other service. Files remain in the selected Google Drive folders until changed or deleted by the owner or the configured synchronization process. Operational logs and secrets are subject to the retention and security practices of the hosting services.

Access and revocation

The owner can revoke the app's Google account access at any time in Google Account security settings. This prevents further authorized synchronization until access is granted again.

Contact

For questions about this personal utility, contact the maintainer via GitHub profile.
