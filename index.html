Rclone Drive Sync

Personal utility for publishing PDF documents to Google Drive

What does it do?

Rclone Drive Sync is a private, owner-operated automation that publishes PDF files from a private GitHub repository to selected folders in the owner's Google Drive using GitHub Actions and rclone.

It is not a public file-sharing service, does not provide user registration, and is not intended for use by third parties. The documents and repository are not made publicly accessible through this website.

Google Drive access

Google OAuth is used only to authorize the owner's rclone connection to Google Drive. Drive access is used to list destination folders and synchronize PDF files. No Google account data is sold or used for advertising.

Learn more about how Google data is handled in our Privacy Policy.
